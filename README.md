Navigation bar with links: Home, About, Services, Project, Contact Me
Hero section with a typing animation ("Hi, My name is Khushboo... Web designer")

Developer illustration on the home section
Built with plain HTML, CSS and JavaScript (no frameworks)

**Tech Stack**
HTML5 - structure
CSS3 - styling and layout
JavaScript - typing animation and interactivity
